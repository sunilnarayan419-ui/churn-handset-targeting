# Repository guide

This document maps the project tree to responsibilities and identifies which files are source, generated output, local-only data, and operational configuration.

## Top-level map

| Path | Responsibility | Commit? |
|---|---|---|
| `.github/workflows/ci.yml` | Ruff, Python 3.10–3.12 tests, Neo4j integration, Docker build | Yes |
| `.github/workflows/docs.yml` | Manuscript build/publication workflow | Yes |
| `.github/dependabot.yml` | Dependency update configuration | Yes |
| `.env.example` | Documented environment variable names and safe placeholders | Yes; never real secrets |
| `.gitignore` | Excludes local data, model artifacts, secrets, caches and generated outputs | Yes |
| `pyproject.toml` | Package metadata, dependency extras, CLI entry point, pytest and Ruff settings | Yes |
| `src/churn_targeting/` | Application source package | Yes |
| `tests/` | Unit, API, artifact and integration tests | Yes |
| `scripts/` | Repeatable training/API checks and report/manuscript utilities | Yes |
| `docs/` | Technical and operational documentation | Yes |
| `content/` | Manubot manuscript source and figures | Yes |
| `build/build.sh`, `build/manuscript.css` | Manuscript build source files | Yes |
| `build/variables.json` | Generated manuscript variables | No; regenerated by workflow |
| `output/` | Built manuscript output | Usually no; generated |
| `data/README.md`, `data/raw/.gitkeep` | Data instructions and empty directory placeholder | Yes |
| `data/raw/Client.csv`, `Record.csv` | Assignment source data | **Never commit** |
| `models/.gitkeep` | Keeps empty model directory in Git | Yes |
| `models/churn_model.joblib`, `*.json` | Locally trained bundle and metadata | Not by default; regenerate locally |
| `reports/` | Reported analysis, notebook results, PDF/PPTX deliverables | Review each output before committing |
| `notebooks/` | Exploratory/assignment notebook | Yes, after checking outputs for sensitive data |
| `Dockerfile`, `docker-compose.yml` | API container and optional Neo4j stack | Yes |
| `Makefile` | Common developer commands for Unix-like shells | Yes |
| `LICENSE`, `CITATION.cff`, `CHANGELOG.md`, `CONTRIBUTING.md` | Legal, citation, release and contributor metadata | Yes |

## Python package map

| Module | Responsibility |
|---|---|
| `config.py` | Environment-backed paths, base rate, API key and Neo4j settings |
| `data.py` | Read source files, join on `Customer_ID`, data-quality validation/reporting |
| `features.py` | Feature exclusions, categorical/numeric handling, scikit-learn pipeline |
| `modeling.py` | Train/test split, optional randomized search, model fit, calibration, metrics, persistence and scoring |
| `calibration.py` | Platt calibration and odds-based base-rate adjustment |
| `targeting.py` | Risk ranking, deciles and top-fraction targeting statistics |
| `bands.py` | Shared definitions for handset age, tenure and other cohort bands |
| `finance.py` | Retention-wave economics, break-even save rate and annualisation |
| `pilot.py` | Two-arm randomised pilot sample-size calculation |
| `analytics.py` | Pandas cohort summaries and allowed dimensions |
| `graph.py` | Optional Neo4j schema, batch loading and cohort queries |
| `cli.py` | `validate`, `train`, `graph-load` and `serve` commands |
| `api/main.py` | FastAPI app factory, lifespan, auth dependency and endpoints |
| `api/schemas.py` | Pydantic request and response contracts |

## Test map

- `test_data.py`, `test_features.py`, `test_bands.py`: input handling, feature preparation and cohort definitions.
- `test_modeling.py`, `test_calibration.py`, `test_targeting.py`: training behavior, calibration and targeting metrics.
- `test_finance.py`, `test_pilot.py`, `test_analytics.py`: deterministic business logic.
- `test_api.py`: endpoint contracts, status codes, API-key behavior and injected model/data fixtures.
- `test_artifacts.py`, `test_cli.py`: model bundle and CLI behavior.
- `test_graph_unit.py`: graph logic with a fake/injected driver.
- `test_graph_integration.py`: real Neo4j parity tests; requires the `integration` marker's external service.

Tests use synthetic fixtures created in `tests/conftest.py`. They do not establish that the assignment data are valid or that the reported results reproduce on the supplied dataset.
